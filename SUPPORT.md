# Support

## Using RepoAura

See the [README](README.md) for setup and usage. RepoAura is a prompt file for GitHub Copilot in VS Code; it is not a standalone application.

## Questions and problems

- Use a **bug report** for a reproducible defect in the prompt or documentation.
- Use a **feature request** for a proposed improvement.
- For general usage questions, open a GitHub discussion if discussions are enabled for this repository; otherwise, use a clearly titled issue.
- For a security concern, follow [SECURITY.md](SECURITY.md) and do not post sensitive details publicly.

Include the prompt version, VS Code/Copilot version when relevant, selected harness, expected behavior, observed behavior, and minimal reproduction steps. Remove secrets and private repository content before sharing.

Support is provided on a best-effort basis; no response time is guaranteed.
